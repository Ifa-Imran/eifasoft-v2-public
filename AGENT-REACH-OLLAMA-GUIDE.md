## 🔧 Using Agent-Reach with Ollama

Agent-Reach doesn't directly integrate with Ollama - it provides tools that your Ollama-based AI agents can use. Here's how to set it up:

### Option 1: Use with OpenClaw + Ollama (Recommended)

Since you already have MetaClaw running with Ollama, you can use Agent-Reach as the "eyes and ears" for your agent:

1. **Configure OpenClaw to use Agent-Reach tools:**
   ```bash
   # Tell your agent it can use agent-reach commands
   agent-reach install --env=local
   ```

2. **Example prompts for your Ollama agent:**
   ```
   "Search for recent tweets about AI agents" 
   → Agent will use: xreach search "AI agents"
   
   "Read this YouTube video transcript: [URL]"
   → Agent will use: yt-dlp --dump-json [URL]
   
   "Check GitHub issues for this repository"
   → Agent will use: gh issue list owner/repo
   
   "Find Reddit discussions about machine learning"
   → Agent will search via Exa MCP
   ```

### Option 2: Direct CLI Usage

Use Agent-Reach commands directly in your terminal:

```bash
# Read any web page
curl https://r.jina.ai/https://example.com

# Extract YouTube subtitles
yt-dlp --dump-json "https://youtube.com/watch?v=VIDEO_ID"

# Search GitHub
gh search repos "machine learning framework"

# Read RSS feeds
python -c "import feedparser; print(feedparser.parse('https://example.com/rss'))"

# Check status
agent-reach doctor
```

### Option 3: MCP Server Integration

Agent-Reach provides an MCP server for advanced integrations:

```bash
# Start the MCP server
python -m agent_reach.integrations.mcp_server

# In your MCP client configuration, add:
{
  "mcpServers": {
    "agent-reach": {
      "command": "python",
      "args": ["-m", "agent_reach.integrations.mcp_server"]
    }
  }
}
```

## 🛠️ Troubleshooting

### Issue: "gh CLI not found"
**Solution:** Add to PATH manually:
```powershell
$env:Path += ";$env:LOCALAPPDATA\GitHub CLI\bin"
[Environment]::SetEnvironmentVariable("Path", $env:Path, "User")
```

### Issue: "yt-dlp returns errors"
**Solution:** Update yt-dlp:
```bash
pip install -U yt-dlp
```

### Issue: "Reddit blocked my request"
**Solution:** Use Exa search instead or configure residential proxy

### Issue: "Can't access XiaoHongShu"
**Solution:** Requires Docker and MCP server setup (see above)
