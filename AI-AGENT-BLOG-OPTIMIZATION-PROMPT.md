## 🚨 COMMON ISSUES TO AVOID

1. **Don't over-optimize** - Keep keyword density natural (1-2%)
2. **Don't use generic CTAs** - Match CTA to blog topic
3. **Don't link to wrong pillar** - Match pillar to blog category
4. **Don't forget to update dates** - Set `updatedAt` to current date
5. **Don't remove existing good content** - Only add, don't delete valuable sections
6. **Don't create duplicate FAQ questions** - Check other blogs in same category
