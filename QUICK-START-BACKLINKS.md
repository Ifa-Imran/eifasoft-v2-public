# ⚡ Quick Start Guide - Cross-Platform Backlink Automation

## 🎯 In 5 Minutes or Less

### Prerequisites (2 min)
```bash
# 1. Install Python packages
pip install requests python-dotenv

# 2. Copy environment template
copy .env.example .env

# 3. Get API keys (open .env and fill in):
#    - GitLab: https://gitlab.com/-/profile/personal_access_tokens
#    - Medium: https://medium.com/me/settings/security
#    - Dev.to: https://dev.to/settings/extensions
#    - Bitbucket: https://bitbucket.org/account/settings/app-passwords/
```

### Run Automation (3 min)
```powershell
# One command to rule them all!
.\run-all-automations.ps1
```

**That's it!** The scripts will:
- ✅ Create 64 GitLab repositories
- ✅ Generate GitBook documentation site
- ✅ Convert all READMEs to Medium articles
- ✅ Set up tracking spreadsheets

## 🔧 Troubleshooting

### Script Fails?
```bash
# Check Python version (need 3.7+)
python --version

# Reinstall dependencies
pip install --upgrade requests python-dotenv

# Run scripts individually for debugging
python scripts/automate-gitlab-import.py
```

### API Errors?
- Double-check credentials in `.env`
- Ensure API tokens have correct permissions
- Wait 5 minutes and retry (rate limiting)

### Content Issues?
- Review generated files before publishing
- Adjust templates in scripts if needed
- Test with small batch first (5-10 services)
