#### Binary Plan Implementation

```python
def calculate_binary_commission(left_leg_volume, right_leg_volume, commission_percentage):
    """
    Calculate binary commission based on weaker leg volume
    
    Args:
        left_leg_volume: Total PV/BV on left leg
        right_leg_volume: Total PV/BV on right leg
        commission_percentage: Commission rate (e.g., 10 for 10%)
    
    Returns:
        Commission amount
    """
    weaker_leg = min(left_leg_volume, right_leg_volume)
    commission = (weaker_leg * commission_percentage) / 100
    return commission

# Example calculation
left_pv = 5000
right_pv = 7000
commission_rate = 10

earnings = calculate_binary_commission(left_pv, right_pv, commission_rate)
print(f"Binary Commission: ${earnings}")  # Output: $500
```

## FAQ Section

### 1. What is recharge MLM software?
​**Recharge MLM software** is a specialized platform designed for mobile recharge distribution businesses using multi-level marketing model. It combines telecom recharge functionality with network marketing compensation plans, enabling distributors to earn commissions from both direct sales and team performance while managing recharge transactions seamlessly.

### 2. How does binary compensation plan work in recharge MLM?
A **binary compensation plan** in recharge MLM uses a two-leg structure (left and right). Commissions are calculated based on the weaker leg's volume, typically ranging from 5-15%. The system automatically balances volumes and calculates pair matching bonuses, daily capping, and carry forward benefits.

### 3. What are essential features in MLM software?
Essential **MLM software features** include: cloud-based architecture, multiple compensation plans (binary, matrix, unilevel), ePIN management, automated payout processing, real-time reporting, mobile app integration, payment gateway support, SMS/email notifications, genealogy tree visualization, and robust security with role-based access control.

### 4. Can recharge MLM software integrate payment gateways?
Yes, advanced **recharge MLM software** supports multiple payment gateway integrations including Stripe, PayPal, Razorpay, Paytm, and bank APIs. These integrations enable secure deposit/withdrawal processing, automated transaction recording, PCI DSS compliance, and support for multiple currencies.

### 5. Is mobile app available for recharge MLM system?
Modern **recharge MLM software** includes native mobile apps for Android and iOS with features like instant recharge, balance checking, commission tracking, team management, fund transfers, push notifications, and biometric authentication for enhanced security.

### 6. How to calculate spillover in binary MLM plan?
**Spillover calculation** tracks when upline sponsors place distributors in downline. Formula: `Spillover Count = Total Downline - (Width^Depth - 1)`. Smart algorithms auto-fill positions strategically to maximize team growth and ensure fair distribution of benefits across the network.
