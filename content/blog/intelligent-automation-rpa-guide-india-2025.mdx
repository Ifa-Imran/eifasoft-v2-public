## RPA vs Intelligent Automation

| Feature | RPA | Intelligent Automation (IPA) |
|---|---|---|
| Process type | Rule-based, structured | Unstructured + rule-based |
| AI component | None | ML, NLP, Computer Vision |
| Document handling | Structured forms only | Any document format |
| Decision making | Pre-defined rules | ML-based decisions |
| Handles exceptions | Limited | Learns from exceptions |

**Use RPA for**: Structured, rule-based, high-volume processes.
**Use IPA for**: Processes involving unstructured data, judgment, or documents like invoices.

## Process Selection Framework

Not all processes should be automated. Score each process:

| Criterion | Score 1 | Score 2 | Score 3 |
|---|---|---|---|
| Volume | <10/day | 10-100/day | >100/day |
| Rule clarity | Complex rules | Some judgment | Pure rules |
| Stability | Changes often | Occasional | Never changes |
| Error cost | Low | Medium | High |
| Manual time | <30 min/day | 30-120 min/day | >2 hours/day |

**Total 12-15**: Excellent RPA candidate. **8-11**: Good candidate. **Below 8**: Not suitable.

## Implementation Steps

1. **Process discovery** (Week 1–2): Map all processes, score candidates
2. **Bot design** (Week 3–4): Document step-by-step bot workflow
3. **Development** (Week 5–8): Build, test in dev environment
4. **UAT** (Week 9–10): Business user testing with real data
5. **Production deployment** (Week 11): Go-live with monitoring
6. **Hypercare** (Week 12–14): Intensive monitoring + exception handling

## FAQ

**Q: What if the process changes? Does the bot break?**
Bots are tested against process variations. For processes that change frequently, Eifasoft builds adaptive bots with configurable rules or adds ML-based decision layers.

**Q: Is our data safe with bots accessing our systems?**
Bots operate with dedicated service accounts, principle of least privilege, full audit logging, and encrypted credential vaults. All bot activity is auditable.

**Q: What's the ROI timeline for RPA?**
Most Eifasoft clients recover their RPA investment within 6–18 months. High-volume data entry automation (1000+ transactions/day) often pays back within 3 months.
