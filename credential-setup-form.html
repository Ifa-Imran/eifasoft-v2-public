🔑 API Credential Setup

Configure your EifaSoft backlink automation credentials

1. GitLab Personal Access Token Pending
  1. Click "Open GitLab" button below
  2. Click "Add new token"
  3. Name: EifaSoft Backlink Automation
  4. Select scopes: api, write_repository, read_user
  5. Click "Create personal access token"
  6. COPY THE TOKEN IMMEDIATELY (won't show again!)
  7. Paste it in the field below
🚀 Open GitLab Token Page
2. Medium Integration Token Pending
  1. Click "Open Medium" button below
  2. Scroll to "Integration tokens" section
  3. Click "Generate token"
  4. Name: EifaSoft Automation
  5. COPY THE TOKEN
  6. Paste it in the field below
🚀 Open Medium Settings
3. Dev.to API Key Pending
  1. Click "Open Dev.to" button below
  2. Scroll to "API key" section
  3. Click "Generate API Key"
  4. COPY THE KEY
  5. Paste it in the field below
🚀 Open Dev.to Settings
4. Bitbucket App Password Pending
  1. Click "Open Bitbucket" button below
  2. Click "Create app password"
  3. Label: EifaSoft Automation
  4. Permissions: Repositories (Write), Account (Read)
  5. Click "Create" and COPY THE PASSWORD
  6. Paste it in the field below
🚀 Open Bitbucket Settings

✅ Success!

Your .env file has been configured!
